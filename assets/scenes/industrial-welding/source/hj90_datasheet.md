## 定位

星光眼（90 瞳距电动防护版）用于工业智能焊接，做工件定位、焊缝提取、焊接规划、焊缝跟踪。

它是主动式双目立体视觉 3D 相机，输出点云、深度图、灰度图。强光、反光、黑色吸光物体场景下仍做高精度建模。电动翻盖挡住焊渣飞溅，风冷散热。

焊前配合猛虎智能焊接应用平台做工件扫描、焊缝提取、焊接规划。焊接中可切到动态模式做焊缝跟踪，实时纠偏。

结构（正面示意）：

- 防护翻盖
- 摆动机构 + 内置激光器
- 右目、左目

## 工作方式

轻量化，可直接装在机械臂上。风冷控制温升。电动翻盖降低焊渣维护成本。成像抗弧光、强光和反光。

| 模式 | 何时用 | 扫描方式 |
|---|---|---|
| 静态 | 焊前：工件扫描、建模、提缝、规划顺序 | 相机与被测物体相对静止，激光线左右摆动 |
| 动态 | 焊接中：焊缝跟踪、实时修正路径 | 物体与相机相对运动，激光线扫过物体 |

覆盖“建模 → 定位 → 跟踪 → 监测”。

## 应用场景

型材焊接、大型工件焊接、多层多道焊接、钢结构焊接。示意安装方式是相机固定在焊枪附近，与焊枪一起装在机械臂末端。

## 系统连接

```
电源输入
    |
星光眼电动防护相机  ——千兆网线—— 网络设备 —— 计算机 / 工控机（猛虎平台）
    |                              |
    └── 电源线 ── 机械臂控制柜 ────┘
         |
      焊接机械臂 + 焊接工件
```

电源线和千兆网线分开。相机装在机械臂末端，朝向工件。
