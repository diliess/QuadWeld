# A04 类角接缝定位

后续已按要求扩展 A15、A03、A21 的 T 接头整体视角测试，见 [三工位整体视角](t_station_overviews.md)。本页以下保留 A04 历史范围和结果。

最新要求已明确：**三条交线均为焊缝**，并已完成机械臂不同关节角度测试，见 [A04 机械臂多角度三焊缝测试](a04_arm_angle_test.md)。以下保留早期只以竖直名义路径评价的历史结果；其中底部两线不应按最新目标集称为多余或误检。

当前只处理 A04 这类具有明显转折的内角接头，保持正常初始臂姿，不继续扩展 A02 共面对接缝。同步采集脚本默认只拍 A04；焊缝定位评价入口默认只处理 A04 左右目。历史数据保留。

## 本次改动与结果

此前 A04 左目的 SAM 板件掩码落在机器人部件上，限定区域内没有形成有效接缝。角接缝模式现在会再用整图预测深度和原几何规则搜索，保留深度置信、已有焊道排除和接触一致性检查，并明确记录回退来源。既有 SAM 结果能产生接缝时继续使用原结果；平面不会被强行生成角缝。

`vision.weld_detector.detect(..., recover_missing_corners=True)` 启用该模式；现有通用图片流程默认关闭，避免把此次角接缝策略扩散到其他接头。A04 评价入口启用它，且不接收焊缝坐标、评价真值或文件名作为几何判定依据。

复用与上次完全相同的 RGB、SAM 和标定 Nested 深度，仅改变接缝后处理。新结果在 `outputs/benchmarks/nested_a04_corners_20261110_01/`：

| 视图 | 改前候选 | 改后候选 | 对应目标竖缝均距 | 目标候选 P95 | 名义根部覆盖 @10 mm |
|---|---:|---:|---:|---:|---:|
| A04 左目 | 0 | 3 | **3.09 mm** | **6.03 mm** | 99.32% |
| A04 右目 | 3 | 3 | **3.31 mm** | **5.55 mm** | 98.97% |

“对应目标”由独立评价阶段核对，尚未由工艺逻辑自动选出。两个视图都保留目标竖缝及两条底部接触线；没有根据真值只留下误差最小的线。由于当前名义真值只标注竖直路径，全候选到它的均距仍为左目 154.59 mm、右目 182.05 mm，10 mm 内点占比为 32.53% / 29.75%。该统计不能被单条目标候选的低误差替代。

## 使用

```bash
# 默认只运行 A04 左右目，从本机 SAM 环境获得语义掩码
.venv/bin/python scripts/benchmark_stereo_seams.py --gpu 0

# 复用已完成且图像哈希一致的 SAM 结果；本次修复验证使用此方式，无需 GPU
.venv/bin/python scripts/benchmark_stereo_seams.py \
  --semantic-cache outputs/benchmarks/nested_seams_20261110_01/semantics.npz \
  --output-dir outputs/benchmarks/nested_a04_corners_new

# 仅重算当前 A04 预测的评价及图像
.venv/bin/python scripts/benchmark_stereo_seams.py --evaluate-only \
  --output-dir outputs/benchmarks/nested_a04_corners_20261110_01
```

语义缓存按 RGB SHA-256 选取左右目，不按文件名或工位标签复用。深度文件也验证 RGB 哈希。改变拍摄视角或深度配置后应生成新的源数据及运行目录。

## 查看

结果目录的 `README.md` 包含每条候选、回退记录、误差和图像索引：

- `A04_initial_arm_left_overview.png` / `right_overview.png`：原图、深度、接缝叠加。
- `*_seams.png`：增加局部、三维曲线和已知二维位置诊断。
- `predictions/*.json`：`corner_recovery` 记录初始拟合面数、初始接缝数、回退原因与恢复数量。
- `seam_points.csv`：各候选三维坐标与逐点有效性；分路径、分有效区间读取。

青色为自动接缝候选，品红虚线为独立评价真值；不能把品红线作为识别输出。当前保留所有具有几何支持的角接触线，是否作为目标焊缝仍需工艺选择。

本次继续使用已知 90 mm 基线尺度校正，没有按焊缝真值拟合尺度、偏移或旋转，也没有修改相机或机器人位姿。A04 路径大部分超过 800 mm 工作距离，结果仅适用于本次静态仿真。17 项单元检查通过，包括错误平面掩码恢复角缝、有效语义保持、纯平面不产生角缝。
