# A15 / A03 / A21：焊枪退出视野后的复测

后续已把目标拉近到650 mm并按左中右三个重叠视角复测，见 [近距离工作范围测试](t_station_close_views.md)。以下是远距离无焊枪对照。

2026-11-10，结果见 [完整报告](../outputs/benchmarks/t_station_unobstructed_20261110_01/README.md)。

相机与焊枪原先刚性连接，移动机械臂不能改变焊枪在相机中的投影。此次在独立 USD 覆盖层中把相机沿光学 +X（双目基线方向）侧移 **50 mm**，外壳、双目光心、安装座、包络碰撞体同步移动，连接板同步延长。焊枪本体网格及可见性保持原值；输入为完整640×1100 RGB，没有裁边或图像遮罩。

原相机中点在焊枪坐标系的平移约为 `[-0.053, -0.104, 0.1181] m`，新值为 `[-0.053, -0.154, 0.1181] m`，旋转不变。记录的新外参在 `station_plan.json → mount_adjustment`，不能当作旧安装标定继续使用。

机器人底座反向平移补偿这50 mm，保持上一轮各工位的相机世界位置、朝向、内参、90 mm双目基线和机械臂关节角。仍是原来优先看全工件的视角，焊缝光轴深度约1.61–2.20 m，均超出800 mm额定工作距离。未执行行走或关节控制轨迹。

## 验证

- 左右目分别检查367167个可见焊枪三角形，均不与视锥相交。
- RTX语义标注逐像素确认三工位共六目焊枪占用均为 **0**；掩码仅供核验，不作为模型输入。
- 另用原左目安装关系对同一个可见焊枪拍摄正对照，必须检出焊枪像素，防止把标注失效误认为无焊枪。
- 腹板和底板全部顶点在左右目内留4%边距；每目840 mm前侧名义路径完整入画。
- 新覆盖层显式声明米制/Z轴向上，并检查独立渲染深度与CAD几何距离的比例约为1，避免USD默认厘米造成尺度错误。
- 复核静态碰撞、四足接地、支撑多边形以及相机载荷平移后的组合质心/惯量。支架新增质量和刚度未知，不代表实机安装或动态验证。

Nested仍输入双目RGB与K/E，保留90 mm已知基线尺度校正；未按焊缝或RTX真值拟合尺度、偏移、旋转。SAM阈值和几何识别规则保持一致。深度前后对比另使用两轮可见工件内部掩码交集，保证评价像素相同。

|---|---:|---:|---:|
| A15 | 57.42 / 58.25 mm | 119.26 / 107.76 mm | 116.04 / 107.35 mm |
| A03 | 38.32 / 33.36 mm | 47.96 / 40.20 mm | 46.80 / 37.66 mm |
| A21 | 134.87 / 130.12 mm | 202.26 / 193.28 mm | 225.51 / 220.09 mm |

六目各提取一条接缝候选，名义焊缝10 mm覆盖率均为0。焊枪退出视野已实现，但此次六目的焊缝三维均距均增大，不能把画面更干净当作定位更准。相同工件像素的深度MAE仅A03右目有所改善（43.92→37.66 mm），其余增大；不能把全部位置误差归因于焊枪遮挡。

最终米制数据的渲染深度/CAD距离比为0.999998–1.000211，正对照检出76476个焊枪像素，六张测试图均为0。调试阶段遗漏根层单位声明的厘米数据已单独标为无效，不参与以上指标。
