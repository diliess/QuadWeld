# 前景横板、竖板的 SAM3 提示

2026-11-10：在 A15、A03、A21 的三张中间视角难例上实际比较20组文字提示，结果保存在 `outputs/benchmarks/plate_prompts_20261110_01/pilot`。`vertical metal plate` 等短语会漏检；部分带 `foreground` 的提示能召回前景，但将横、竖两个板面合成一个对象。文字提示结果全部保留。

本次采用深度引导的交互提示，在已有18张图上运行本地 SAM3.1 multiplex 的正负点分割模式：

1. 使用已有六图联合 Nested 深度与相机姿态，在预测距离300–800 mm内拟合平面。
2. 按平面法向与世界竖直方向的关系选取主要水平面、竖直面。提示点在平面内部自动分散采样。
3. 每个面取正点，另一个面和远处背景取负点，分别调用 SAM3.1 输出两个实例。
4. 保留范围内 SAM 像素；两实例重叠处按预测点到两个拟合平面的距离归属，保留与提示平面相连的分量。

没有读取 CAD、渲染深度真值或人工坐标来选择对象。原始 SAM 掩码、最终掩码、逐图提示点与平面参数均保存。18张图都得到两个非空且互不重叠的掩码；边缘和部分内部仍有缺口，不能将这个计数解释为像素准确率100%。

[完整分割图](../outputs/benchmarks/foreground_plate_parts_20261110_01/README.md)中橙色为横板，青色为竖板。原始焊缝测试报告保持原版本。

```bash
.venv-sam/bin/python scripts/segment_foreground_plates.py \
  --run-dir outputs/benchmarks/t_station_joint_20261110_01 \
  --output-dir outputs/benchmarks/foreground_plate_parts_new --gpu 0
```

输出的 `semantics.npz` 与已有缓存接口兼容，实例顺序为横板、竖板。SAM3.1 对点提示对象写入的分数1.0是 API 指定对象的分数，不是实测质量。缓存中保留传统检测阈值字段以兼容读取器，并明确记录点提示模式及掩码概率阈值。

联合测试入口新增 `--semantic-cache PATH` 可读取这份缓存。当前未重新评价焊缝误差；仅使用新缓存检查后续感知接口时，18张图中2张直接使用SAM掩码得到交线，16张仍触发几何回退，其中1张没有交线。掩码分离改善不等同于后续接触线判定已经改善。

为与现有应用共享显存，视觉编码器按块在CPU/GPU间调入，保持原权重精度。两个几何提示/掩码归属单元检查通过，18张结果已核对范围、互斥性、图像哈希和可视化。
