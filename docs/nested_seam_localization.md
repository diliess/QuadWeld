## 误差如何计算

预测阶段只读取：原始 RGB、已保存的标定 Nested 深度、内参、深度置信和固定类别提示的 SAM 掩码。

- 既有焊道中心线：接受的 SAM 区域骨架 → 采样 Nested 深度 → 内参回投。
- 没有接受焊道覆盖的接缝候选：现有 DA3 板面拟合 → 两平面交线 → 几何有效区间。

本次未修改识别器或 SAM 阈值。Nested 使用此前的 90 mm 基线尺度校正；没有进一步用焊缝真值拟合尺度、偏移、旋转或 ICP。预测文件全部写完后，独立评价函数才打开 USD 和 RTX 真值。

独立真值采用 `/World/Fixtures/{工位}/WeldSeams` 下的名义焊接路径，按不超过 1 mm 的弧长间距采样。它们在原场景中默认隐藏，未出现在模型输入 RGB 中；4 mm 的显示宽度是参考线样式，不是焊道直径。本次评价名义根部路径，不评价实物焊趾。

自动定位误差为有效预测点到**画面内有限名义路径**的最近三维距离。路径端点不会无限延长，不跨无效间断连接。覆盖率反向计算：名义路径样本到有效预测线段的距离是否在 10 / 20 mm 内。没有输出的视图记为 N/A、覆盖率为 0，不记作零误差。

名义根部可能被坡口表面遮挡，主评价仍将画面内根部作为目标。附加记录最近 RTX 表面与根部 Z 相差不超过 3 mm 的样本数：A02 左右目均为 0/858；A04 左右目为 291/292 和 292/292。这个标记不用于挑选预测点或删除主评价目标。

表中的“已知二维根部投影诊断”由**评价器**把名义路径投影到图像，读取对应 DA3 深度后回投，与原名义三维点比较。这相当于已提供二维位置，包含遮挡根部与可见表面的差异；它既不是自动识别误差，也不是单纯的可见板面深度误差。

## 图像和数据

每个视图提供两张图：

- `*_overview.png`：原始 RGB、米制深度、原图上的接缝候选与参考根部。
- `*_seams.png`：增加接缝局部放大、相机坐标三维图和沿根部的已知二维投影诊断。

青色是自动板面交线候选；绿色预留给接受的焊道中心线（本次没有）；品红虚线是独立名义真值，仅用于评价。未检出视图标有红色 `NO AUTOMATIC SEAM`。各图深度色阶统一为 0.3–1.2 m，显示饱和不改变保存数据。

`predictions/*.npz/json` 保存自动曲线、三维点、有效标记、拟合面、SAM 分数和输入哈希。`evaluation/*.npz/json` 单独保存真值和逐点误差。`seam_points.csv` 保存候选在相机及世界坐标系中的米制坐标、有效性和到名义路径的距离；不同路径和无效区间不能直接连接。`summary.json` 保存完整指标、模型来源和代码哈希。

## 复跑

在 QuadWeld 根目录执行：

```bash
# 复用此前同步采集及标定 Nested 深度；自动寻找本机 SAM3 环境
.venv/bin/python scripts/benchmark_stereo_seams.py --gpu 0

# 显式指定新的双目深度运行目录
.venv/bin/python scripts/benchmark_stereo_seams.py \
  --source-run outputs/benchmarks/nested_stereo_20261110_01 \
  --output-dir outputs/benchmarks/nested_seams_new --gpu 0

# 仅在 CPU 上重算已有预测的误差与图像
.venv/bin/python scripts/benchmark_stereo_seams.py --evaluate-only \
  --output-dir outputs/benchmarks/nested_seams_20261110_01
```

`--resume` 复用对应图像哈希的语义缓存，重新执行预测及评价。新建运行需要源目录中的 `captures` 和 `predictions/stereo_calibrated` 数据；源数据生成方法见 [双目深度说明](nested_stereo_depth.md)。

本次发现 SAM 权重链接仍指向已经不存在的 `/data/model/sam3`，已修复为本机已有 `/data/models/sam3`，没有下载或更换权重。

14 项单元检查通过，其中新增检查覆盖有限线段端点、断点、不存在输出、三维距离统计、像素中心和亚像素深度采样。结果只描述当前两组静态仿真预设；A04 路径大部分超过 800 mm 工作距离，且采用理想相机位姿，不代表实机焊接定位精度。
